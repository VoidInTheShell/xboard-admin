# XBoard Admin 前端风格规范

> 本文件是 Xboard-Admin 的前端视觉与交互基线。页面级规范如与本文冲突，必须先更新本文并说明原因，不能在业务页面中静默另起一套样式。

## 1. 产品气质

- 面向基础设施、节点与订阅运维，优先保证信息密度、状态辨识和操作效率。
- 主视觉使用中性黑、白、灰；成功、警告、危险色只用于真实状态和校验结果。
- 采用 shadcn/Radix 组件语义和 Lucide 图标，不引入第二套组件语言。
- 界面克制、紧凑、可审计；不使用营销式大标题、渐变、玻璃拟态、装饰性插画和无意义动效。
  唯一例外：登录页（`login-page.tsx`）面向管理员个人化展示，允许整页背景图、左侧全高瀑布毛玻璃分栏（OpenWrt Argon 风格）和缓慢流动的高光动效，具体边界见第 9 节。

## 2. 设计令牌

令牌以 `src/index.css` 为唯一实现来源。业务组件必须使用语义类名，不直接写新的品牌色。

| 角色 | 规则 |
|---|---|
| 主色 | `primary` 为近黑色，主按钮、激活状态和强强调统一使用 |
| 页面背景 | `background` 使用浅灰白；内容表面使用 `card` / `popover` |
| 次级表面 | 使用 `secondary`、`muted`、`accent`，不得自行增加蓝色 CTA |
| 边界 | 以 `border` / `input` 细边框建立层级，常规卡片不依赖重阴影 |
| 焦点 | 使用 `ring`，键盘焦点必须清晰可见 |
| 状态 | success=绿色、warning=琥珀色、danger=红色；必须同时配文字或图标 |

字体：

- 界面与标题：DM Sans，中文回退到系统中文字体。
- ID、端口、倍率、时间、配置值：JetBrains Mono 或 `font-data`。
- 常用字号：12px 辅助信息、14px 正文、16px 区块标题、24px 页面标题。
- 页面标题不超过 28px，不使用超大展示字体。

尺寸与形状：

- 基础圆角令牌为 `--radius: 0.75rem`。
- 按钮、输入框、菜单项通常使用 `rounded-xl`。
- 弹窗、配置侧栏、浮动菜单通常使用 `rounded-2xl`。
- 默认按钮高度 40px，紧凑按钮 36px，大按钮 44px。
- 桌面表格保持紧凑；窄屏可点击目标尽量不小于 44px。
- 页面内容最大宽度统一为 1600px，页面内间距以 8px 节奏递增。

## 3. 页面结构

标准管理页顺序：

1. 面包屑；
2. 页面标题、说明和主要操作；
3. 可选统计摘要或作用域信息；
4. 搜索、筛选和次要操作；
5. 表格、表单或编辑器主体。

规则：

- 页面使用 `mx-auto w-full max-w-[1600px]`。
- 页面说明只解释当前对象和作用域，不重复按钮名称。
- 同一层级只保留一个主要操作；次要操作使用 outline 或菜单收纳。
- 服务器工作区必须持续显示服务器身份、区域、内核、状态和对象数量，不能混淆服务器、入站、发布主机和业务节点。

## 4. 导航层级

### 4.1 全局侧栏

- “仪表盘”是直接入口。
- 其余导航按“基础设施、用户与订阅、运营与支持、财务与系统”分组。
- 展开侧栏时，父级按钮可展开/收起，箭头和内容使用 200ms 动画。
- 当前路由所属分组默认展开，当前链接同时使用文字和背景表示激活。
- 折叠侧栏时只显示分组图标；hover 或键盘 focus 后在右侧显示可交互浮动子菜单。
- 浮动子菜单必须可点击、可继续 Tab 导航，不能用 Tooltip 冒充菜单。
- 品牌区折叠按钮与 Logo 共用槽位；折叠后 hover/focus 将 Logo 切换为展开图标，不得引起布局跳动。

### 4.2 路由级导航

- 服务器工作区的“入站、主机、证书、出站、路由、Xray 配置”属于跨页面导航，保留横向下划线形式。
- 窄屏允许横向滚动，但页面本身不能产生横向滚动。
- 路由级导航不得改造成配置步骤侧栏。

### 4.3 表单内分类

- 系统配置、Xray 配置、订阅模板和配置弹窗使用左侧分类按钮，不横向平铺成长条 Tabs。
- 页面内侧栏使用 page sticky，固定在顶栏下方，并限制为当前可视区高度。
- 弹窗内侧栏使用 container sticky，以弹窗正文滚动区为参照。
- 分类过长时只滚动侧栏自身，并阻止滚动链传递。
- 移动端取消 sticky，侧栏与内容上下堆叠。
- sticky 祖先禁止使用 `overflow-x-hidden`；需要裁剪时使用不会创建滚动容器的 `overflow-x-clip`。

共享实现：`src/components/control-plane/catalog-form.tsx`。

## 5. 组件规范

### 5.1 Button

- 必须复用 `src/components/ui/button.tsx`，不要在页面中重写按钮基类。
- default 用于唯一主操作；outline 用于次要操作；secondary 用于弱强调；ghost 用于行内或图标操作；destructive 只用于危险动作。
- default/outline/secondary hover：上移 1px并增加轻阴影；active：回到原位并缩放至 0.98。
- 尾部箭头使用 `data-icon="inline-end"`，hover 时轻微右移。
- 禁用状态不保留位移或缩放。
- 图标按钮必须提供 `aria-label`。

### 5.2 Button Group

- “主操作 + 更多菜单”等连续动作必须使用 `ButtonGroup`。
- 组内按钮共享外轮廓，内部接缝无重复圆角和重复边框。
- 禁止用两个独立按钮加 `gap` 模拟组合按钮。

### 5.3 Switch、Checkbox、Toggle

- Switch 默认尺寸为 48×28px；开为近黑底白色滑块，关为灰色轨道。
- Switch、Checkbox、Toggle 与选项卡片统一使用 200ms 状态过渡和明确焦点环。
- 点击态可轻微缩放，但不得造成周围布局变化。
- 开关必须与可点击的 label 关联，不只依赖视觉位置。

### 5.4 输入与表单

- 使用 `FieldGroup / Field / FieldLabel / FieldDescription` 组织字段。
- 所有输入必须有可见标签；说明、错误和敏感性提示放在控件附近。
- 普通字段桌面可双列；Textarea、多选、代码编辑器和其他高控件默认跨两列。
- 控制高控件显示的主开关也应独占整行，避免 CSS Grid 产生大块空白。
- 条件隐藏后不得保留空 section；整个步骤无字段时使用明确 Empty 状态。

### 5.5 长配置编辑器

- 所有 Catalog `control: "code"` 字段必须使用共享 Monaco `ConfigEditor`。
- JSON、YAML、纯文本必须声明正确语言模式。
- 编辑器提供行号、换行、复制、清空、JSON 格式化、状态反馈和全屏模式。
- 编辑器必须懒加载，不得并入普通管理页首屏包。
- 普通描述、备注和短文本继续使用 Textarea；禁止用深色 Textarea 冒充代码编辑器。

### 5.6 Card 与统计摘要

- 常规 Card 是静态边框表面，默认无悬浮位移；只有真正可点击的卡片才允许 hover 反馈。
- 避免多层 Card 套 Card；优先用边框、分隔线和标题区建立结构。
- 统计卡显示“标签、主值、简短口径、状态图标”，数据必须从当前数据源派生，禁止写死一套独立数字。
- 状态统计不得混淆语义，例如维护不能计入离线。
- 五项统计在 XL 单行展示，较窄屏依次降为三列、两列和单列。

### 5.7 Table

- 表头简短，数值列使用等宽数字，辅助信息使用 muted 文本。
- 操作列靠右；常用动作直接显示，低频动作进入更多菜单。
- 宽表格放在自身横向滚动容器内，不能撑宽整个页面。
- 空表格提供原因与下一步，不只显示空白。

### 5.8 Dialog

- 使用 `rounded-2xl`、细边框、遮罩和 overlay 级阴影。
- 长弹窗采用固定 Header、可滚动正文、固定 Footer。
- 多步骤或多分类弹窗必须使用左侧按钮侧栏，不横向均分。
- Footer 右侧排列“取消 + 主操作”；关闭图标必须有 hover、focus 和可访问名称。
- 弹窗高度不超过视口，移动端保留至少 16px 外边距。

### 5.9 Badge 与状态

- Badge 只承载短标签、状态或类型，不放长句。
- 状态 Badge 使用图标 + 文字 + 轻量语义色，不能只靠颜色。
- 普通分类使用 secondary/outline，不滥用成功色。

## 6. 动效

- 默认时长 200ms，使用 ease-out。
- Overlay 和短浮层可使用 150–200ms 淡入、缩放或轻位移。
- 只过渡实际需要的属性，避免无边界的 `transition-all`。
- 禁止页面切换编排、弹跳、旋转装饰和大幅位移。
- 所有动效必须支持 `prefers-reduced-motion`，降级后交互状态仍清晰。
- 静态内容不为了“活泼”增加 hover 动画。

## 7. 响应式

- 关键检查宽度：375、768、1024、1440px。
- 窄屏操作按钮允许换行或收进菜单。
- 双列表单在窄屏变为单列。
- 配置侧栏在窄屏置于正文上方。
- 表格优先自身滚动；页面 `document.scrollWidth` 不得超过视口宽度。
- 固定、sticky、浮层和全屏编辑器必须分别验证桌面与移动端边界。

## 8. 可访问性

- 键盘 focus 必须清晰；不可用 `outline: none` 后不提供替代焦点环。
- 当前路由使用 `aria-current="page"`，展开按钮使用 `aria-expanded`。
- 视觉隐藏但仍挂载的内容使用 `inert` 和 `aria-hidden`，不得残留在 Tab 顺序中。
- Icon-only Button、菜单触发器和拖拽入口必须提供可访问名称。
- 表单错误不能只用红色表示；状态颜色必须配文字或图标。
- 正文与背景对比度至少满足 WCAG AA。

## 9. 禁止项

- 禁止新增蓝色品牌主色、渐变、玻璃拟态和装饰性大阴影；例外仅限登录页（见下）。
- **登录页例外（2026-09 更新）**：管理员可在「系统配置 → 主题控制 → 管理后台」自定义登录页背景图、登录框毛玻璃不透明度、背景遮罩透明度（使用 shadcn Slider 滑块调整）与登录页主题色（原生取色器 + 十六进制输入，留空跟随全局主题）。布局：左上角站点 logo 与名称；桌面端登录框位于左侧全高、比表单稍宽的毛玻璃面板（`backdrop-blur` + `color-mix(in srgb, var(--card) N%, transparent)`，默认 60%，可调 0-95），背景图上叠加可调暗色遮罩（默认 40%，可调 0-90）；填写主题色后通过在登录页根节点覆盖 `--primary` 与 `--ring`，将登录按钮与表单焦点高亮切换为所选强调色；面板内叠加缓慢的竖向高光（`login-waterfall-sheen`，约 7.5s 循环）。移动端无标题，登录卡片居中。该高光为纯装饰，必须在 `prefers-reduced-motion: reduce` 下自动停用（已由全局规则处理）。除登录页外，任何页面不得引入背景图、毛玻璃或类似装饰。
- 禁止 Emoji 充当界面图标；统一使用 Lucide。
- 禁止复制一套页面专用 Button、Switch、Tabs 或 Dialog 样式。
- 禁止把表单子菜单横向均分成一整排。
- 禁止用两个独立组件模拟 Button Group。
- 禁止给静态 Card 增加暗示可点击的浮起动画。
- 禁止写死可由当前数据计算的统计数字。
- 禁止用 Textarea 替代长配置编辑器。
- 禁止让 sticky 菜单因错误 overflow 祖先随页面滚走。
- 禁止仅凭 HTTP 200 宣称视觉、交互或资源加载验收通过。

## 10. 交付检查

每轮前端改动至少确认：

- [ ] 复用了共享组件和语义令牌，没有新增局部视觉体系。
- [ ] 主操作、组合操作、危险操作的层级正确。
- [ ] hover、active、focus、disabled 和 reduced-motion 状态完整。
- [ ] 侧栏开合、折叠浮层、当前路由和键盘导航正常。
- [ ] 长表单侧栏滚动后仍可见，过长时可独立滚动。
- [ ] 375/768/1024/1440px 无页面级横向溢出。
- [ ] 长配置使用 Monaco 且保持懒加载。
- [ ] ESLint、TypeScript typecheck、Vite production build 通过。
- [ ] 本地预览完成真实视觉检查后，再进入后端、提交、推送或部署阶段。
